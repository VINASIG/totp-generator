The same dashed information surface contains a persistent label, a native paste textarea, and ordered Choose image, Paste image and Scan with camera actions. The choose action is primary. All actions are adjacent to the input. Container sizing adapts the same layout in either product. Labels, icons, focus, drag, disabled and forced-colors states are shared. Camera settings and product-specific URL handling may be revealed outside this intake. Root tool layout and TOTP's import disclosure serve different product contexts.

Camera acquisition requires the explicit scan action. No image upload, secret persistence, automatic URL navigation or clipboard polling is introduced. Stop tracks and reject stale results on cancellation, clear, navigation or source change.
