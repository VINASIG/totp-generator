# TOTP sharing verification

This record covers the direct share-link feature and the key-field password-generation symptom on 7 October 2026. The clean baseline was main at e91d64de1fdf03437b5bc734fd22e2093ffca226. The owner selected immediate code generation and accepted that possession of a share link grants access to the TOTP key. See [the design decision](share-decision-2026-10-07.md).

Only public RFC and synthetic keys were used. The user's screenshot and its contents were not imported into test data or published evidence. No dependency, shared header/footer, preference runtime or cryptographic primitive was replaced.

## Failures found and repaired

The first sharing run had 47 passes and four failures. Three engines exposed a startup-order bug where the final locale redirect could lose a credential already consumed by the earlier page. Initialization now waits for the reviewed preference initialization and skips a page already redirecting. The additional Firefox failure was a clock fixture attempting to pause at an already elapsed starting instant. The fixture now installs at 58 seconds and pauses at the unchanged 59-second reference point. Expectations and product budgets were not relaxed. The initial browser report and traces remain at output/share-2026-10-07/first-run-playwright.

A typed-lint failure in the CSS-support fallback test exposed an any return from Reflect.apply. The test wrapper now returns the correctly typed CSS.supports boolean. No lint rule was disabled.
